  • Screenshot automation

    2021

    A Node pipeline for visual review of whole websites. It pulls a site's sitemap.xml, extracts every URL, screenshots each page with Puppeteer, compiles the lot into a single PDF, uploads it to Azure Blob Storage and pushes it into Filestage for sign-off. URL parameters trigger specific page states, like opening the cookie dialog.

    • Node.js
    • Puppeteer
    • PDFKit
    • Azure Blob Storage
    • Azure AD
