  • Screenshot Automation Tool

    A Node pipeline for visual review of whole websites. It pulls a site's sitemap.xml, extracts every URL, screenshots each page with Puppeteer, compiles the lot into a single PDF, uploads it to Azure Blob Storage and pushes it into Filestage for sign-off. URL parameters trigger specific page states, like opening the cookie dialog.

    • Node.js
    • Puppeteer
    • PDFKit
    • Azure Blob Storage
    • Azure AD

$ cat about.txt

Front-end developer based in Zadar, Croatia, seven-plus years into building web applications. I started in the Vue ecosystem against Laravel and Spring Boot back ends, and I've worked mostly in React and TypeScript since.

I came to development through design rather than around it. My degree is in media communications from the University of Maribor, and most of it was interface work: prototyping, design systems, and putting people in front of a screen to find out what actually confuses them. That's why I'm comfortable taking a Figma file apart, and why I'd rather settle a flow before it's built than after.

The through-line is working out what I'm building before I build it — the workout log above started as a spec document and got implemented against it. I'm equally happy away from the browser: the screenshot pipeline exists because manually capturing a few hundred pages before every release was a miserable way to spend an afternoon.

The fastest way to reach me is email.

Built with plain HTML and CSS. No build step.
